## Covered assets

The CC BY 4.0 grant applies to the original Iskra artwork, including:

- `assets/v6/` — the current V6 artwork set (38 animations × 8 frames,
  256×256 source PNGs), and the packaged copies of the same frames under
  `plugin/iskra/assets/v6/` produced by `scripts/build-plugin.py`;
- `assets/branding/raspberry-flame.png` and `.svg` — the original,
  owner-approved laptop badge (see `docs/BRANDING.md`);
- `plugin/iskra/icon.svg` — the plugin icon;
- `docs/media/iskra.gif` — the README hero animation, built from the real
  V6 frames by `scripts/build-readme-gif.py`.

Older artwork, rejected/source sheets, moodboard images and private
working history are not included in this public snapshot.

Generated machine-readable listings that accompany the frames (for
example `assets/*/manifest.json` and `plugin/iskra/assets/animations.luau`)
are build data and fall under the MIT license with the rest of the code.
