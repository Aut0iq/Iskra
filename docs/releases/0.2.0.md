## 0.2.0 — steady flame

This release establishes the development and delivery foundation. Iskra's
job is still to watch your agents; her own build now gets supervision too.

- Protected dev/main promotion through CI and a repository-scoped GitHub App.
- Required Rust, RustSec, Luau, packaging and three-platform checks; verified
  immutable nightly delivery and author-approved stable packages.
- Portable avatar toolkits for Linux, Windows and macOS: start with a portrait,
  validate animated packs and build a credited custom plugin.
- Versioned theme/personalization schemas. Runtime pack switching and themes
  remain future work.
- Desktop installs retain all artwork and dependency notices.
- Stable probe fixtures under parallel forks; one main CI per App promotion.
- Shorter README, contributor guidance and Star History.

Zeron plugins and avatar tools are portable. The optional native desktop
companion remains Linux/Wayland x86_64. Nightly plugin staging is unsigned;
stable plugins require the author's local Zeron signature.
