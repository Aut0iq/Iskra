## 0.2.2 — correctness fixes

- Chat navigation from the desktop companion no longer leaves zombie
  helper processes inside the long-lived pet process.
- Desktop-control commands in the Zeron plugin release their pending
  lock when dispatch fails synchronously, so later control actions can
  recover without a plugin reload.

The native desktop companion remains Linux/Wayland x86_64. The Zeron
plugin and avatar tools are portable.
