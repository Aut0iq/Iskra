## 0.2.1 — correctness fixes

- The desktop companion stays visible for maximized Hyprland windows and
  remembers a pinned monitor across disconnects. Drag reactions recover
  when a new press interrupts settling.
- Zeron status handling accepts both chat metadata field styles and
  tolerates null JSON-RPC error and MCP structured-content fields.
- Usage refresh can recover from a synchronous read error. The desktop
  reader reports unusable usage data and avoids an unintended relative
  cache path when HOME is unset.
- Incomplete desktop packages are rejected. CI requires the expected
  desktop archive, checksum manifest and three portable staging archives.

The native desktop companion remains Linux/Wayland x86_64. The Zeron
plugin and avatar tools are portable.
